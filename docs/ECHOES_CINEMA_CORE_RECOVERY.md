# Echoes Cinema Core Recovery

## Mission

Recover the existing Luma-like video project inside EchoesEngine and turn it into a proven, modular video pipeline without mislabeling control stubs as real generation.

## Target flow

```text
song + treatment
  -> music analysis
  -> story / scene graph
  -> shot list
  -> Prompt Director
  -> camera plan
  -> video model worker
  -> continuity checks
  -> clip QC
  -> interpolation
  -> upscale / restoration
  -> beat-synced assembly
  -> final export
```

## Stage 0 — Repository truth inventory

Inspect and classify:

- `scene/`
- `camera/`
- `render/`
- `ai/`
- `ai_prompt/`
- `export/`
- `api/`
- `platform/`
- worker control plane
- EchoesStudio proxy routes

For every module record:

- build target
- public headers
- source files
- implemented behavior
- external dependencies
- test coverage
- runtime proof
- status: `REAL`, `PARTIAL`, `MOCK`, `DORMANT`, `BROKEN`, `MISSING`

## Stage 1 — Compile the Cinema runtime

Build target:

```text
ECHoesEnginePro
```

Required proof:

- clean configure
- clean Release build
- executable produced
- startup logs
- module registration list
- no silent fallback to audio-only mode

## Stage 2 — Deterministic render proof

Before AI video generation, prove the native scene/camera/render/export path with a deterministic project:

- one scene
- one camera
- one animated transform
- one light or visual layer
- three-second render
- H.264 MP4 export
- FFprobe QC

This separates engine/render failures from model-worker failures.

## Stage 3 — Real local video worker

Replace the diffusion control stub with one explicit backend adapter.

Adapter contract:

```json
{
  "backend": "local-video-model",
  "mode": "text-to-video|image-to-video",
  "prompt": "...",
  "negativePrompt": "...",
  "seed": 1234,
  "frames": 49,
  "fps": 24,
  "width": 768,
  "height": 432
}
```

Required behavior:

- dependency detection
- model availability check
- VRAM estimate
- bounded timeout
- stdout/stderr capture
- output manifest
- explicit failure status
- no mock fallback unless requested

## Stage 4 — Music video intelligence

Add structured artifacts:

1. `MusicAnalysis`
   - BPM
   - downbeats
   - sections
   - energy curve
   - vocal/instrumental regions

2. `VisualTreatment`
   - story premise
   - visual language
   - palette
   - locations
   - character bible

3. `ShotPlan`
   - shot ID
   - start/end time
   - prompt
   - camera
   - continuity references
   - seed
   - intended transition

## Stage 5 — Continuity

Implement explicit continuity state:

- character reference images
- wardrobe ID
- hair/makeup descriptors
- environment ID
- lens language
- palette
- seed lineage
- previous-frame/reference conditioning

No claim of character continuity without a repeated-subject test across at least three shots.

## Stage 6 — Post-processing

Pipeline order:

```text
raw clip
  -> decode validation
  -> frame interpolation
  -> upscale / restoration
  -> stabilization if requested
  -> color normalization
  -> audio sync
  -> final encode
```

Each stage must be independently switchable and report its backend.

## Stage 7 — Video QC

Minimum checks:

- container and codecs
- resolution
- FPS
- duration
- file size
- black frames
- frozen frames
- duplicate-frame ratio
- corruption/decode failures
- missing audio
- A/V sync drift
- loudness and clipping

Statuses:

- `PASS`
- `WARNING`
- `FAIL`

## First real milestone

A single 3–5 second clip generated by a real local video model, passed through the Echoes Cinema pipeline, exported to MP4, and validated by QC.

## First product milestone

A 20–30 second music teaser containing:

- at least four generated shots
- beat-aware cuts
- one consistent principal subject
- interpolation
- upscale
- final audio mux
- downloadable MP4
- complete job manifest

## Safety and cost rules

- no infinite generation loops
- no unattended cloud spending
- no automatic model downloads without an explicit size report
- no automatic code merge
- no customer delivery of mock output
- every backend named in the result manifest
